# 投資研究：巴菲特-芒格-段永平-李錄 四大師綜合分析框架

## 研究框架

基於巴菲特、芒格、段永平、李錄四位投資大師的方法論，按以下七個模塊順序執行研究：

### 前置步驟：AI研究偏見自覺（必須執行）

在開始研究前，先評估該公司的"AI可研究性"，識別潛在的數據偏見：

**信息豐富度評級**：
| 等級 | 特徵 | AI研究陷阱 | 應對策略 |
|------|------|-----------|---------|
| A級（信息充裕） | 上市多年、券商覆蓋多、媒體報道密集 | 共識過強，AI輸出趨同於市場定價，alpha有限 | 重點做反面檢驗：聰明人爲什麼不買？被忽略的風險是什麼？ |
| B級（信息適中） | 上市1-3年、覆蓋有限、部分數據需推算 | AI可能用"合理推測"填補空白，看起來完整實則虛假確定性 | 每個推算數據標註置信度，區分"有據推算"和"憑空填充" |
| C級（信息稀缺） | 剛上市/冷門股/新興市場、幾乎無覆蓋 | AI會因資料不足而過度保守，誤判爲"看不清=不好" | 用第一性原理提問（見下方），從有限信息中提取商業本質 |

**C級公司的第一性原理研究法**：
當公開資料不足時，不要試圖拼湊出"看起來完整"的報告，而是聚焦以下底層問題：
1. 客戶是誰？爲什麼付錢？有沒有替代選擇？
2. 復購靠什麼驅動？是習慣、鎖定、還是持續創造新價值？
3. 競爭對手拿100億能複製這門生意嗎？
4. 管理層做過什麼關鍵決策？這些決策反映了什麼判斷力和價值觀？

**偏見自查清單**（研究全程保持警惕）：
- [ ] 我的"確定性"感受是來自生意本質，還是來自資料數量？
- [ ] 如果把這家公司的資料量減少一半，我的結論會變嗎？
- [ ] AI輸出的分析是否與市場共識高度雷同？如果是，我的信息優勢在哪？
- [ ] 是否存在"公開資料很少但生意本質極好"的可能性被低估了？

將信息豐富度評級結果寫入報告開頭，並在最終結論中註明"AI研究置信度"與"實際投資確定性"的區別。

### 第一步：數據收集

> **數據源規範**：參見 `skills/financial-data.md`。所有財務數據必須來自兩個獨立來源，誤差>1%須標記。
> - 美股：macrotrends（主）+ stockanalysis（副）
> - 港股：aastocks（主）+ macrotrends ADR（副）
> - A股：東方財富（主）+ 巨潮資訊（副）

使用 Task 工具啓動後臺 Agent，從網絡收集以下數據：

1. 收入結構：最近財年及近4季度分部收入、增速、毛利率
2. 財務指標：近5年收入、淨利潤、毛利率、經營利潤率、自由現金流、現金儲備
3. 競爭格局：市場份額、主要競爭對手對比
4. 商業模式與護城河：核心競爭優勢來源
5. 技術能力：核心技術棧、研發投入
6. 管理層：創始人/CEO履歷、持股比例、關鍵決策記錄
7. 行業前景：TAM（總可尋址市場）、增長預測
8. 風險因素：地緣政治、監管、供應鏈等
9. 當前估值：市值、PE、PS、PEG、EV/Revenue
10. 多空雙方核心論點

#### 數據交叉驗證（必須執行，使用金融嚴謹性工具）

數據收集完成後，**必須調用 `tools/financial_rigor.py` 對關鍵數據進行程序化驗證**，杜絕LLM心算誤差。

**必須驗證的數據點**：
- 總股本（從交易所、Yahoo Finance、StockAnalysis 等至少2個源確認）
- 當前股價和市值（**手動計算 股價×總股本 並與報告市值對比，防止單位錯誤**）
- 最近財年收入和淨利潤（從公司年報+至少1個第三方源確認）
- 現金儲備和淨現金（現金+短期投資-總債務，注意口徑差異）
- 管理層持股比例（區分經濟權益和投票權，注意AB股結構）

**強制驗證步驟（使用Bash調用工具）**：

Step 1 — 市值驗算（精確十進制，非浮點）：
```bash
python3 tools/financial_rigor.py verify-market-cap \
  --price {股價} --shares {總股本} --reported {報告市值} --currency {幣種}
```

Step 2 — 關鍵數據多源交叉驗證：
```bash
python3 tools/financial_rigor.py cross-validate \
  --field {字段名} --values '{"來源1": 數值, "來源2": 數值}' --unit {單位}
```
對收入、淨利潤、現金儲備分別執行。

Step 3 — 估值指標精確驗算（PE/PB/ROE/FCF Yield 等）：
```bash
python3 tools/financial_rigor.py verify-valuation \
  --price {股價} --eps {EPS} --bvps {每股淨資產} --fcf-per-share {每股FCF} --dividend {每股股息}
```

**驗證規則**：
1. 每個關鍵數據點至少2個獨立來源
2. 發現來源間有差異時，優先採用公司年報/交易所數據，並註明差異原因
3. **所有涉及計算的數據必須通過工具驗算，禁止LLM心算**
4. 工具輸出結果直接嵌入報告附錄"關鍵數據交叉驗證記錄"
5. 如果工具報告 ❌ 偏差過大，必須排查原因後才能繼續分析

**常見錯誤防範**：
- 市值單位：港幣億 vs 人民幣億 vs 美元億，容易漏寫/多寫一個零
- FCF口徑：不同來源對資本支出的定義可能不同（是否含租賃、收購等）
- 債務口徑：是否包含經營租賃負債
- 持股比例：AB股公司的經濟權益 ≠ 投票權

### 第二步：生意本質分析 — 段永平"對的生意"

分析要點：
- 用一句話定義這門生意的本質
- 收入結構拆解（圖表）

- **段永平式追問**：這門生意好在哪？如果只能用一句話描述，是什麼？

### 第三步：護城河評估 — 巴菲特"經濟護城河"

逐一驗證五類護城河：

| 護城河類型 | 驗證方法 |
|-----------|---------|
| 品牌/定價權 | 是否能在不損失銷量的情況下提價？ |
| 轉換成本 | 客戶遷移到競品的成本有多高？ |
| 網絡效應 | 用戶越多產品越好嗎？ |
| 規模效應 | 規模帶來的成本優勢有多大？ |
| 技術/專利壁壘 | 技術領先幾年？能否被複制？ |

分析護城河趨勢：過去5年變寬還是變窄？未來5年預判。

**巴菲特式追問**：10年後這條護城河還在嗎？什麼能摧毀它？

### 第四步：逆向思考與風險清單 — 芒格"反過來想"

- 列出"這家公司可能失敗的所有路徑"（表格：路徑/概率/影響程度）
- 歷史類比：找到歷史上處於相似位置的公司，結局如何？
- 跨學科分析：用網絡效應理論、技術採納曲線、競爭博弈等模型交叉驗證
- 偏誤自查：敘事偏差、錨定效應、倖存者偏差
- 收集空方核心論點

**芒格式追問**：我最可能在哪裏犯錯？聰明人爲什麼會不買/做空這家公司？

### 第五步：管理層評估 — 段永平"對的人" + 巴菲特"管理層誠信"

- CEO/創始人關鍵決策覆盤（表格：時間/決策/結果/評分）
- 資本配置能力：研發回報率、併購成功率、回購時機
- 股東利益一致性：管理層持股、薪酬結構、減持記錄
- 組織能力：團隊穩定性、關鍵人才風險
- 企業文化特徵

**段永平式追問**：如果CEO退休，這家公司還能保持競爭力嗎？

### 第六步：行業與文明趨勢 — 李錄"文明演進框架"

- 判斷所在行業是否處於"文明級範式轉移"
- 歷史技術革命類比（蒸汽機/電力/互聯網/AI）
- TAM增長曲線與天花板分析
- 公司在產業價值鏈中的位置
- 技術路線風險
- 客戶/供應商集中度分析

**李錄式追問**：站在20年後回看，這家公司是"這個時代的標準石油"還是"曇花一現的3Com"？

### 第七步：估值與安全邊際 — 巴菲特"內在價值" + 段永平"對的價格"

- 當前市場定價（關鍵估值指標表格）—— **必須通過工具驗算**
- 反向DCF：當前股價隱含了什麼增長預期？
- 三情景估值 —— **必須通過工具精確計算，禁止心算**：
```bash
python3 tools/financial_rigor.py three-scenario \
  --price {股價} --eps {EPS} --shares {總股本億} \
  --growth {樂觀增速} {中性增速} {悲觀增速} \
  --pe {樂觀PE} {中性PE} {悲觀PE} --years 3 --currency {幣種}
```
- 與自身歷史估值對比
- 與同行估值對比

**段永平式追問**：如果股市明天關閉5年，你願意以這個價格持有嗎？

### 第八步：市場情緒與入場時機

基本面決定"買什麼"，市場情緒決定"何時買"。即使生意再好、估值再合理，錯誤的入場時機也可能導致中期大幅浮虧。

**必須收集的市場情緒數據點：**

1. **波動率指標**：VIX（美股）、HVIX（港股）、KOSPI200-VIX（韓股）——當前值及相對歷史分位
2. **空頭持倉比例 (Short Interest)**：佔流通股本百分比，趨勢（上升/下降）
3. **選項市場信號**：Put/Call 比率、隱含波動率 Skew（Put IV vs Call IV）
4. **宏觀環境**：當前利率水平、收益率曲線形態、聯儲局政策立場（降息/加息/按兵不動）
5. **技術面參考**：股價相對 200 日均線位置、RSI（超買/超賣）、是否處於下降通道
6. **分析師情緒**：共識評級分佈（強烈買入/買入/持有/賣出比例）、近期目標價調整方向

**情緒解讀框架：**

| 情緒狀態 | 信號組合 | 對入場時機的意義 |
|---------|---------|--------------|
| **極度悲觀** | VIX >30 + 高空頭 + Put 溢價大 + 股價遠低于 200DMA | ✅ 安全邊際最佳，適合加倉 |
| **中性偏空** | VIX 20-25 + 空頭中等 + 股價在 200DMA 附近震盪 | ⚠️ 可分批建倉 |
| **中性偏多** | VIX 15-20 + 分析師一致看多 + 股價在 200DMA 上方 | ⚠️ 小倉位試探，等待回調 |
| **極度樂觀** | VIX <15 + 空頭極低 + 股價遠高于 200DMA + RSI >70 | ❌ 避免追高，等待修正 |

**關鍵原則：**
- 市場情緒是**時機工具**，不是**決策依據**。好公司在壞情緒中是機會，壞公司再好情緒中仍是陷阱
- 如果基本面評分 ≥4 星但情緒為"極度樂觀"，建議將建倉規模減半、延後入場
- 如果基本面評分 ≤2 星但情緒為"極度悲觀"，可能是價值陷阱，不抄底

**巴菲特式追問**：市場先生今天的心情是機會還是噪音？我應該利用他的情緒，還是被他的情緒利用？

## 數據抽檢（準出流程）

報告寫入文件後，**必須**執行數據抽檢，通過後方可發佈：

**Step 1 — 提取抽檢清單（15%隨機抽樣）：**
```bash
python3 tools/report_audit.py extract \
  --report <報告文件路徑>
```
輸出 JSON 模板，每項含 `fetched_value`（待填）。

**Step 2 — 取數覈驗：**
對清單中每個數據點，按 `skills/financial-data.md` 規範從可靠信源取數
（美股：macrotrends+stockanalysis；港股：aastocks+macrotrends；A股：東方財富+巨潮資訊），
填入 `fetched_value` / `fetched_source` / `fetched_value2` / `fetched_source2`。

**Step 3 — 輸出判決：**
```bash
python3 tools/report_audit.py verdict \
  --results '<填好的JSON>' \
  --report <報告文件名>
```

- **【準出】**：所有抽檢點偏差 ≤ 1% → 報告可發佈
- **【打回】**：任意點偏差 > 1% → 修正對應數據後重新抽檢，直到準出
