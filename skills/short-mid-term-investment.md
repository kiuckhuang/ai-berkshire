# 短中期投资研究框架（0-24个月）

对 $ARGUMENTS 进行短中期（短期0-6个月 + 中期6-24个月）投资研究分析。

**支持输入格式**：`公司名/代码` 或 `公司名 时间框架`，例如：`RMBS`、`Ouster 中期`。默认同时评估短（0-6月）与中（6-24月）两个时间框架。

> **定位声明**：本Skill与 `investment-research.md`（长期价值投资）互补。长期框架回答"这是不是一门值得持有一辈子的好生意"，本框架回答"未来0-24个月内，这只股票能不能带来超额回报、以及如何控制风险"。**短中期投资是交易/周期决策，不是长线价值判断**——同一家"好公司"可能在短期高估，同一家"平庸公司"可能在中期有反弹机会。

## 前置步骤：AI研究偏见自觉（必须执行）

短中期投资的AI研究陷阱与长期不同：

| 陷阱 | 表现 | 应对 |
|------|------|------|
| **近因偏差** | AI过度放大最新事件（财报、新闻），忽略周期位置 | 把最新事件放进"事件日历"，而非当作趋势 |
| **动能追涨** | 因股价上涨就看好，用"最近涨得好"代替基本面 | 技术面信号必须与估值/基本面交叉验证 |
| **时间框架混淆** | 用长期故事论证短期买入 | 每个结论必须注明适用的时间框架（短/中） |
| **假确定性** | 对短中期预测（业绩、催化剂时点）给出过度精确的数字 | 催化剂时间点标注为"概率+区间"，非单点 |

**偏见自查清单**：
- [ ] 我是在分析"公司的价值"，还是在分析"股价的涨跌"？
- [ ] 我的结论依赖的催化剂，在未来0-6月/6-24月内大概率会发生吗？
- [ ] 如果判断错了，止损在哪？我能承受吗？
- [ ] 短中期结论是否被长期叙事（好公司）带偏了？

将信息丰富度评级（沿用A/B/C框架）写入报告开头。

## 第一步：时间框架与催化剂事件追踪

### 1.1 明确时间框架定位

| 框架 | 时长 | 驱动因素 | 主导分析方法 |
|------|------|---------|-------------|
| **短期** | 0-6个月 | 事件驱动（财报、政策、产品发布、指数调整、资金流） | 催化剂日历 + 技术面 + 情绪 |
| **中期** | 6-24个月 | 趋势驱动（盈利周期、行业供需、估值回归） | 盈利趋势 + 估值分位 + 供需格局 |

### 1.2 催化剂事件日历

列出未来24个月内可能影响股价的**可证伪事件**，标注时间窗口、方向（利多/利空）、影响程度、发生概率：

| 时间 | 催化剂 | 类型 | 方向 | 影响 | 概率 | 验证信号 |
|------|--------|------|------|------|------|---------|
| 20xx-Qx | 财报季 | 常规 | ？ | 高 | 高 | 营收/EPS vs 共识、指引 |
| 20xx-Qx | 新产品/法规/订单 | 事件 | ？ | 高 | 中 | 官方公告、供应链 |

**必须区分**：
- 🔵 **确定性催化剂**（财报日、指数调整日）——可提前布局
- 🟡 **概率性催化剂**（订单、监管、产品获批）——需概率加权
- ⚪ **叙事性催化剂**（行业热点、AI概念）——不可依赖，易被证伪

> 催化剂追踪的关键是**可证伪性**：如果一个事件无论发生与否都无法改变你的判断，它就不是有效的催化剂。

### 1.3 反向追问

> 如果这个催化剂落空（财报暴雷、订单流产），股价会跌多少？我在入场时是否已为此做好准备？

## 第二步：动能与技术面

技术面在短中期是**时机工具**（何时买卖），不是决策依据（买不买）。

### 2.1 必须收集的技术指标

| 指标 | 用途 | 判断基准 |
|------|------|---------|
| 股价 vs 200日均线 | 中期趋势 | 上方=中期多头，下方=中期空头 |
| 股价 vs 50日均线 | 短期趋势 | 上方=短期强势，下方=短期弱势 |
| RSI (14) | 超买超卖 | >70超买，<30超卖 |
| 成交量 | 确认价格有效性 | 见下方 2.3「量价确认」 |
| 相对量 (RVOL) | 衡量当日活跃度 | 对比20/50日均量：<50%缩量，>150%异常放量，>200%巨量 |
| OBV / 累积派发线 | 判断吸筹 vs 派发 | OBV走平/下行但价跌=派发；OBV与价背离=警讯 |
| 52周高低点 | 位置 | 接近高点=强势但追高风险；接近低点=超跌但可能下跌中继 |
| 均线排列 | 趋势强度 | 多头排列（MA20>MA50>MA200）vs 空头排列 |
| 相对强度 (RS) | 相对大盘 | 跑赢/跑输同类与大盘 |

### 2.2 技术面解读原则

- **顺势为主**：短中期买入优先选择站上关键均线、均线多头排列的标的
- **技术面不背离基本面**：若技术面显示强势但估值极贵且无催化剂，视为"动能陷阱"，不追
- **突破确认**：新高/平台突破需放量确认，避免假突破

### 2.3 量价确认（Volume-Price，核心且必须执行）

成交量是价格的"燃料"，衡量一次价格移动的**确认度与机构背书**。**光看价格/均线不够，必须同时看成交量**。

**量价四象限（判断趋势可信度）**：

| 价格 | 成交量 | 解读 | 操作含义 |
|------|--------|------|---------|
| 上涨 | 放大 | ✅ 真实买盘，趋势健康 | 可顺势持有/加仓 |
| 下跌 | 放大 | ❌ **真实卖压/派发(distribution)**，确认下跌 | **勿抄底**，续跌风险高 |
| 上涨 | 萎缩 | ⚠️ 虚涨/量缩反弹，缺乏机构背书 | **勿追**，易夭折(head fake) |
| 下跌 | 萎缩 | ✅ 无恐慌，卖压衰竭 | 可能是健康回调，观察买盘讯号 |

**量价背离（潜在反转前兆）**：
- **下跌量缩**：价格新低但量能萎缩 → 卖压枯竭，**可能是见底前的条件之一**（需再配反弹放量确认）
- **上涨量缩**：价格新高但量能递减 → 上涨乏力，谨防见顶
- **放量下跌后量缩反弹**：反弹若持续量缩，属低确认度反弹，**不能视为可靠底部讯号**

**关键纪律**：
- **下跌巨量 = 派发，勿接刀**：股价在高于均量大幅放量下跌，反映机构真实出货，确认下跌趋势，此时"买在低位"风险极高
- **安全的抄底讯号是「下跌量缩 → 反弹放量」**：先等卖压枯竭（量缩止跌），再等反弹放量（买盘确认），两个条件齐备才考虑
- **判断时须标注「放量」还是「缩量」**：以20日均量为基准，>150%为放量、<50%为缩量

> **追问**：这波上涨/下跌是**放量还是缩量**？放量下跌=真实派发（勿接刀）；量缩反弹=头假（勿追）。只有在「下跌量缩+反弹放量」的确认组合下，短期入场才具可靠性。

### 2.4 综合技术面评分（均线 × 成交量）

| 股价 vs 200日线 | 下跌放量 | 下跌量缩 | 反弹放量 | 反弹量缩 |
|---------------|---------|---------|---------|---------|
| **下方（空头）** | ❌ 强烈避开，勿接刀 | ⚠️ 观望，等买盘确认 | ⚠️ 观察反转，可小仓试 | ❌ 头假，勿追 |
| **上方（多头）** | ⚠️ 回调警讯，减仓 | ✅ 健康回调，可续持 | ✅ 最强确认，顺势加 | ⚠️ 上涨乏力，警惕

## 第三步：市场情绪与时机

收集以下情绪指标并判断入场时机（沿用 `investment-research.md` 第八步的情绪框架）：

| 指标 | 数值 | 解读 |
|------|------|------|

| 空头持仓比例 | | 高空头+股价上行=轧空潜力；高空头+基本面恶化=危险 |
| Put/Call 比率 | | >1偏空（可能机会），<0.7极度乐观（警惕） |
| 资金流向 | | 主力/机构净流入流出 |
| 分析师情绪 | | 一致看多时警惕共识陷阱 |
| 融资/杠杆数据 | | 过热信号 |

**情绪解读框架**（简化版）：

| 情绪状态 | 信号 | 时机意义 |
|---------|------|---------|
| **极度悲观** | VIX>30 + 高空头 + 股价远低于200DMA | ✅ 机会，适合分批布局（需确认无价值陷阱） |
| **中性** | VIX 15-25 + 股价在200DMA附近 | ⚠️ 等催化剂确认再入场 |

> **追问**：市场先生现在的心情，是让我利用（恐慌买入/乐观卖出），还是利用我（追涨杀跌）？

## 第四步：估值波段回归

短中期估值分析的目标不是"绝对内在价值"，而是**均值回归**——判断当前估值相对历史分位和同行的位置，以及回归的催化剂。

### 4.1 估值分位分析

| 估值指标 | 当前值 | 历史分位 | 同行/指数对比 | 判断 |
|---------|--------|---------|--------------|------|
| PE / 前瞻PE | | | | |
| PS | | | | |
| EV/Revenue | | | | |
| PEG | | | | |
| FCF Yield | | | | |

### 4.2 波段回归逻辑

- **高于历史75分位**：估值扩张已充分，上行空间有限，回归风险高
- **低于历史25分位**：估值压缩充分，若基本面未恶化，回归弹性大
- **短中期估值修正的驱动**：盈利超预期、行业景气拐点、估值切换（成长→价值）

### 4.3 三情景估值（必须通过工具精确计算）

对短中期（0-24月）情景，用 `financial_rigor.py three-scenario`：

```bash
python3 tools/financial_rigor.py three-scenario \
  --price {股价} --eps {EPS} --shares {总股本亿} \
  --growth {乐观} {中性} {悲观} --pe {乐观PE} {中性PE} {悲观PE} \
  --years 1 --currency {币种}
```

> 注意：对未盈利公司（无EPS），改用**营收×PS**情景法（参照 `investment-research.md` 的处理），并明确标注低置信度。**禁止对无EPS公司硬套PE三情景**。

**追问**：当前估值已反映了多少"好消息"？如果利好兑现但低于市场预期，会怎样？

## 第五步：基本面验证（短中期口径）

虽然短中期偏重催化剂和技术，但**基本面是安全网**，防止"价值陷阱"。

- **盈利趋势**：最近2-4季营收/EPS/毛利率的方向（加速/减速/拐点）
- **指引质量**：管理层指引 vs 市场共识的差距（beat/meet/miss）
- **现金流**：是否持续烧钱（短中期尤其警惕现金耗尽风险）
- **基本面拐点信号**：毛利率拐头、订单积压、行业供需逆转

> **追问**：如果未来6个月基本面恶化，这笔交易的止损逻辑是否仍成立？基本面变坏是短中期投资的最大敌人。

## 第六步：止盈止损与仓位纪律（必须执行）

短中期投资的**成败关键是风控**，而非选股。入场前必须预先定义退出条件。

### 6.1 强制建立交易计划

| 项目 | 设定 | 说明 |
|------|------|------|
| 入场价 | | 明确买入触发条件 |
| 目标价（短/中） | | 基于三情景估值与技术压力位 |
| 止损价 | | **必须有**，基于技术支撑或固定比例（如-8%~-15%） |
| 最大仓位 | | 单票占总仓位上限（短中期建议≤5-10%） |
| 持有时限 | | 催化剂落空/逻辑破裂即离场，不无限等待 |
| 止盈策略 | | 分批止盈 / 移动止盈（跟踪20日线） |

### 6.2 止盈止损纪律

- **止损纪律**：触发止损果断执行，不因"它会反弹"而心存侥幸。**先保本，再谈盈利**
- **止盈纪律**：达目标价分批止盈，让利润奔跑同时锁定部分收益
- **逻辑止损**：若买入逻辑（催化剂/基本面/技术）被证伪，即使未触价格止损也应离场
- **加仓规则**：只在"盈利中"加仓（顺势），绝不在亏损中摊平（逆势）

### 6.3 风险计算工具

对每笔交易，用 `financial_rigor.py` 验算风险回报比（RR）与最大损失：

```
风险回报比 RR = (目标价 - 入场价) / (入场价 - 止损价)
优质交易：RR ≥ 2:1
最大损失 = (入场价 - 止损价) × 仓位股数  （必须可承受）
```

> **追问**：这笔交易如果亏损，亏损金额是我能平静接受的吗？如果不能，仓位过大——缩仓。

## 关键原则

- **风控优先于选股**：短中期投资的长期胜率来自严格止损，而非预测准确率
- **时间框架分离**：短期看催化剂与技术，中期看趋势与估值，不要混用
- **顺势而为**：不逆著大趋势操作，技术面与基本面共振时胜率最高
- **可证伪**：每笔交易的逻辑必须有清晰的"如果错了怎么办"
- **不与长期框架冲突**：好公司在短期高估时仍不追高，坏公司在短期反弹时也不追涨
