# 短中期投資研究框架（0-24個月）

對 $ARGUMENTS 進行短中期（短期0-6個月 + 中期6-24個月）投資研究分析。

**支持輸入格式**：`公司名/代碼` 或 `公司名 時間框架`，例如：`RMBS`、`Ouster 中期`。默認同時評估短（0-6月）與中（6-24月）兩個時間框架。

> **定位聲明**：本Skill與 `investment-research.md`（長期價值投資）互補。長期框架回答"這是不是一門值得持有一輩子的好生意"，本框架回答"未來0-24個月內，這隻股票能不能帶來超額回報、以及如何控制風險"。**短中期投資是交易/週期決策，不是長線價值判斷**——同一家"好公司"可能在短期高估，同一家"平庸公司"可能在中期有反彈機會。

---

## 前置步驟：AI研究偏見自覺（必須執行）

短中期投資的AI研究陷阱與長期不同：

| 陷阱 | 表現 | 應對 |
|------|------|------|
| **近因偏差** | AI過度放大最新事件（財報、新聞），忽略週期位置 | 把最新事件放進"事件日曆"，而非當作趨勢 |
| **動能追漲** | 因股價上漲就看好，用"最近漲得好"代替基本面 | 技術面信號必須與估值/基本面交叉驗證 |
| **時間框架混淆** | 用長期故事論證短期買入 | 每個結論必須註明適用的時間框架（短/中） |
| **假確定性** | 對短中期預測（業績、催化劑時點）給出過度精確的數字 | 催化劑時間點標註為"概率+區間"，非單點 |

**偏見自查清單**：
- [ ] 我是在分析"公司的價值"，還是在分析"股價的漲跌"？
- [ ] 我的結論依賴的催化劑，在未來0-6月/6-24月內大概率會發生嗎？
- [ ] 如果判斷錯了，止損在哪？我能承受嗎？
- [ ] 短中期結論是否被長期敘事（好公司）帶偏了？

將信息豐富度評級（沿用A/B/C框架）寫入報告開頭。

## 第一步：時間框架與催化劑事件追蹤

### 1.1 明確時間框架定位

| 框架 | 時長 | 驅動因素 | 主導分析方法 |
|------|------|---------|-------------|
| **短期** | 0-6個月 | 事件驅動（財報、政策、產品發佈、指數調整、資金流） | 催化劑日曆 + 技術面 + 情緒 |
| **中期** | 6-24個月 | 趨勢驅動（盈利週期、行業供需、估值回歸） | 盈利趨勢 + 估值分位 + 供需格局 |

### 1.2 催化劑事件日曆

列出未來24個月內可能影響股價的**可證偽事件**，標註時間窗口、方向（利多/利空）、影響程度、發生概率：

| 時間 | 催化劑 | 類型 | 方向 | 影響 | 概率 | 驗證信號 |
|------|--------|------|------|------|------|---------|
| 20xx-Qx | 財報季 | 常規 | ？ | 高 | 高 | 營收/EPS vs 共識、指引 |
| 20xx-Qx | 新產品/法規/訂單 | 事件 | ？ | 高 | 中 | 官方公告、供應鏈 |

**必須區分**：
- 🔵 **確定性催化劑**（財報日、指數調整日）——可提前佈局
- 🟡 **概率性催化劑**（訂單、監管、產品獲批）——需概率加權
- ⚪ **敘事性催化劑**（行業熱點、AI概念）——不可依賴，易被證偽

> 催化劑追蹤的關鍵是**可證偽性**：如果一個事件無論發生與否都無法改變你的判斷，它就不是有效的催化劑。

### 1.3 反向追問

> 如果這個催化劑落空（財報暴雷、訂單流產），股價會跌多少？我在入場時是否已為此做好準備？

## 第二步：動能與技術面

技術面在短中期是**時機工具**（何時買賣），不是決策依據（買不買）。

### 2.1 必須收集的技術指標

| 指標 | 用途 | 判斷基準 |
|------|------|---------|
| 股價 vs 200日均線 | 中期趨勢 | 上方=中期多頭，下方=中期空頭 |
| 股價 vs 50日均線 | 短期趨勢 | 上方=短期強勢，下方=短期弱勢 |
| RSI (14) | 超買超賣 | >70超買，<30超賣 |
| 成交量 | 確認價格有效性 | 見下方 2.3「量價確認」 |
| 相對量 (RVOL) | 衡量當日活躍度 | 對比20/50日均量：<50%縮量，>150%異常放量，>200%巨量 |
| OBV / 累積派發線 | 判斷吸籌 vs 派發 | OBV走平/下行但價跌=派發；OBV與價背離=警訊 |
| 52週高低點 | 位置 | 接近高點=強勢但追高風險；接近低點=超跌但可能下跌中繼 |
| 均線排列 | 趨勢強度 | 多頭排列（MA20>MA50>MA200）vs 空頭排列 |
| 相對強度 (RS) | 相對大盤 | 跑贏/跑輸同類與大盤 |

### 2.2 技術面解讀原則

- **順勢為主**：短中期買入優先選擇站上關鍵均線、均線多頭排列的標的
- **技術面不背離基本面**：若技術面顯示強勢但估值極貴且無催化劑，視為"動能陷阱"，不追
- **突破確認**：新高/平台突破需放量確認，避免假突破

### 2.3 量價確認（Volume-Price，核心且必須執行）

成交量是價格的"燃料"，衡量一次價格移動的**確認度與機構背書**。**光看價格/均線不夠，必須同時看成交量**。

**量價四象限（判斷趨勢可信度）**：

| 價格 | 成交量 | 解讀 | 操作含義 |
|------|--------|------|---------|
| 上漲 | 放大 | ✅ 真實買盤，趨勢健康 | 可順勢持有/加倉 |
| 下跌 | 放大 | ❌ **真實賣壓/派發(distribution)**，確認下跌 | **勿抄底**，續跌風險高 |
| 上漲 | 萎縮 | ⚠️ 虛漲/量縮反彈，缺乏機構背書 | **勿追**，易夭折(head fake) |
| 下跌 | 萎縮 | ✅ 無恐慌，賣壓衰竭 | 可能是健康回調，觀察買盤訊號 |

**量價背離（潛在反轉前兆）**：
- **下跌量縮**：價格新低但量能萎縮 → 賣壓枯竭，**可能是見底前的條件之一**（需再配反彈放量確認）
- **上漲量縮**：價格新高但量能遞減 → 上漲乏力，謹防見頂
- **放量下跌後量縮反彈**：反彈若持續量縮，屬低確認度反彈，**不能視為可靠底部訊號**

**關鍵紀律**：
- **下跌巨量 = 派發，勿接刀**：股價在高於均量大幅放量下跌，反映機構真實出貨，確認下跌趨勢，此時"買在低位"風險極高
- **安全的抄底訊號是「下跌量縮 → 反彈放量」**：先等賣壓枯竭（量縮止跌），再等反彈放量（買盤確認），兩個條件齊備才考慮
- **判斷時須標註「放量」還是「縮量」**：以20日均量為基準，>150%為放量、<50%為縮量

> **追問**：這波上漲/下跌是**放量還是縮量**？放量下跌=真實派發（勿接刀）；量縮反彈=頭假（勿追）。只有在「下跌量縮+反彈放量」的確認組合下，短期入場才具可靠性。

### 2.4 綜合技術面評分（均線 × 成交量）

| 股價 vs 200日線 | 下跌放量 | 下跌量縮 | 反彈放量 | 反彈量縮 |
|---------------|---------|---------|---------|---------|
| **下方（空頭）** | ❌ 強烈避開，勿接刀 | ⚠️ 觀望，等買盤確認 | ⚠️ 觀察反轉，可小倉試 | ❌ 頭假，勿追 |
| **上方（多頭）** | ⚠️ 回調警訊，減倉 | ✅ 健康回調，可續持 | ✅ 最強確認，順勢加 | ⚠️ 上漲乏力，警惕

## 第三步：市場情緒與時機

收集以下情緒指標並判斷入場時機（沿用 `investment-research.md` 第八步的情緒框架）：

| 指標 | 數值 | 解讀 |
|------|------|------|
| VIX / 波動率指數 | | 高=恐慌（機會），低=樂觀（追高風險） |
| 空頭持倉比例 | | 高空頭+股價上行=軋空潛力；高空頭+基本面惡化=危險 |
| Put/Call 比率 | | >1偏空（可能機會），<0.7極度樂觀（警惕） |
| 資金流向 | | 主力/機構淨流入流出 |
| 分析師情緒 | | 一致看多時警惕共識陷阱 |
| 融資/杠杆數據 | | 過熱信號 |

**情緒解讀框架**（簡化版）：

| 情緒狀態 | 信號 | 時機意義 |
|---------|------|---------|
| **極度悲觀** | VIX>30 + 高空頭 + 股價遠低於200DMA | ✅ 機會，適合分批佈局（需確認無價值陷阱） |
| **中性** | VIX 15-25 + 股價在200DMA附近 | ⚠️ 等催化劑確認再入場 |
| **極度樂觀** | VIX<15 + 分析師一致看多 + RSI>70 | ❌ 追高風險，等回調 |

> **追問**：市場先生現在的心情，是讓我利用（恐慌買入/樂觀賣出），還是利用我（追漲殺跌）？

## 第四步：估值波段回歸

短中期估值分析的目標不是"絕對內在價值"，而是**均值回歸**——判斷當前估值相對歷史分位和同行的位置，以及回歸的催化劑。

### 4.1 估值分位分析

| 估值指標 | 當前值 | 歷史分位 | 同行/指數對比 | 判斷 |
|---------|--------|---------|--------------|------|
| PE / 前瞻PE | | | | |
| PS | | | | |
| EV/Revenue | | | | |
| PEG | | | | |
| FCF Yield | | | | |

### 4.2 波段回歸邏輯

- **高於歷史75分位**：估值擴張已充分，上行空間有限，回歸風險高
- **低於歷史25分位**：估值壓縮充分，若基本面未惡化，回歸彈性大
- **短中期估值修正的驅動**：盈利超預期、行業景氣拐點、估值切換（成長→價值）

### 4.3 三情景估值（必須通過工具精確計算）

對短中期（0-24月）情景，用 `financial_rigor.py three-scenario`：

```bash
python3 tools/financial_rigor.py three-scenario \
  --price {股價} --eps {EPS} --shares {總股本億} \
  --growth {樂觀} {中性} {悲觀} --pe {樂觀PE} {中性PE} {悲觀PE} \
  --years 1 --currency {幣種}
```

> 注意：對未盈利公司（無EPS），改用**營收×PS**情景法（參照 `investment-research.md` 的處理），並明確標註低置信度。**禁止對無EPS公司硬套PE三情景**。

**追問**：當前估值已反映了多少"好消息"？如果利好兌現但低於市場預期，會怎樣？

## 第五步：基本面驗證（短中期口徑）

雖然短中期偏重催化劑和技術，但**基本面是安全網**，防止"價值陷阱"。

- **盈利趨勢**：最近2-4季營收/EPS/毛利率的方向（加速/減速/拐點）
- **指引質量**：管理層指引 vs 市場共識的差距（beat/meet/miss）
- **現金流**：是否持續燒錢（短中期尤其警惕現金耗盡風險）
- **基本面拐點信號**：毛利率拐頭、訂單積壓、行業供需逆轉

> **追問**：如果未來6個月基本面惡化，這筆交易的止損邏輯是否仍成立？基本面變壞是短中期投資的最大敵人。

## 第六步：止盈止損與倉位紀律（必須執行）

短中期投資的**成敗關鍵是風控**，而非選股。入場前必須預先定義退出條件。

### 6.1 強制建立交易計劃

| 項目 | 設定 | 說明 |
|------|------|------|
| 入場價 | | 明確買入觸發條件 |
| 目標價（短/中） | | 基於三情景估值與技術壓力位 |
| 止損價 | | **必須有**，基於技術支撐或固定比例（如-8%~-15%） |
| 最大倉位 | | 單票佔總倉位上限（短中期建議≤5-10%） |
| 持有時限 | | 催化劑落空/邏輯破裂即離場，不無限等待 |
| 止盈策略 | | 分批止盈 / 移動止盈（跟蹤20日線） |

### 6.2 止盈止損紀律

- **止損紀律**：觸發止損果斷執行，不因"它會反彈"而心存僥倖。**先保本，再談盈利**
- **止盈紀律**：達目標價分批止盈，讓利潤奔跑同時鎖定部分收益
- **邏輯止損**：若買入邏輯（催化劑/基本面/技術）被證偽，即使未觸價格止損也應離場
- **加倉規則**：只在"盈利中"加倉（順勢），絕不在虧損中攤平（逆勢）

### 6.3 風險計算工具

對每筆交易，用 `financial_rigor.py` 驗算風險回報比（RR）與最大損失：

```
風險回報比 RR = (目標價 - 入場價) / (入場價 - 止損價)
優質交易：RR ≥ 2:1
最大損失 = (入場價 - 止損價) × 倉位股數  （必須可承受）
```

> **追問**：這筆交易如果虧損，虧損金額是我能平靜接受的嗎？如果不能，倉位過大——縮倉。

報告寫入文件後，**必須**執行數據抽檢，通過後方可發佈：

**Step 1 — 提取抽檢清單（15%隨機抽樣）：**
```bash

  --report <報告文件路徑>
```

**Step 2 — 取數覈驗：**
對清單中每個數據點，按 `skills/financial-data.md` 規範從可靠信源取數
（美股：macrotrends+stockanalysis；港股：aastocks+macrotrends；A股：東方財富+巨潮資訊），
填入 `fetched_value` / `fetched_source` / `fetched_value2` / `fetched_source2`。

**Step 3 — 輸出判決：**
```bash
python3 tools/report_audit.py verdict \

```

- **【準出】**：所有抽檢點偏差 ≤ 1% → 報告可發佈
- **【打回】**：任意點偏差 > 1% → 修正對應數據後重新抽檢，直到準出

## 關鍵原則

- **風控優先於選股**：短中期投資的長期勝率來自嚴格止損，而非預測準確率
- **時間框架分離**：短期看催化劑與技術，中期看趨勢與估值，不要混用
- **順勢而為**：不逆著大趨勢操作，技術面與基本面共振時勝率最高
- **可證偽**：每筆交易的邏輯必須有清晰的"如果錯了怎麼辦"
- **不與長期框架衝突**：好公司在短期高估時仍不追高，壞公司在短期反彈時也不追漲
