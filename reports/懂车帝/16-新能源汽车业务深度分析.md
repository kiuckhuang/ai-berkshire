# 懂車帝新能源汽車業務深度分析

> 研究日期：2026年5月
> 分析維度：新能源轉型機遇、渠道變革、內容生態、競爭格局

---

## 一、新能源汽車在懂車帝平臺的內容與交易佔比

### 1.1 市場大背景：新能源已成絕對主流

中國新能源汽車滲透率在2025年全年達到53.9%，年度滲透率首次超過燃油車。到2026年4月，新能源滲透率歷史性突破60%，懂車帝發佈的全國乘用車零售銷量排行榜Top 10中僅剩一款燃油車型，其餘九席被新能源車包攬。

中汽協預測2026年新能源汽車銷量將達1900萬輛，佔汽車總銷量的比重持續攀升。

### 1.2 懂車帝平臺內容結構的新能源轉向

根據懂車帝發佈的多份報告和平臺數據：

- **用戶意向偏移**：懂車帝DAU持續增長，平臺聚集大量高濃度購車人羣，其中新能源意向用戶佔比已處於高位。女性用戶更傾向接受新能源（尤其純電），新能源用戶在高線城市更集中。
- **內容生態重心轉移**：新能源相關內容熱度飆升，車機、充電、輔助駕駛等專有名詞搜索熱度同比上漲27%。懂車帝已明確將新能源作爲內容扶持的核心方向。
- **創作者結構變化**：科技、財經、數碼等非傳統汽車類作者持續進入新能源內容領域，不少新能源車主實現從用戶到KOC的身份轉化。
- **交易維度**：懂車帝服務以舊換新帶動汽車消費規模接近3800億元（2025年企業社會責任報告數據），新能源是以舊換新的核心驅動品類。

**關鍵判斷**：雖然懂車帝未公開披露新能源內容的精確佔比數字，但從用戶行爲數據、內容搜索熱度、銷量排行榜結構來看，新能源內容佔比大概率已超過50%，且仍在快速提升。這與整體市場滲透率的趨勢高度一致。

### 1.3 用戶行爲差異：燃油車用戶vs新能源用戶

懂車帝2025年4月發佈的用戶行爲報告揭示了一個值得關注的差異：

| 維度 | 自主燃油用戶 | 新能源用戶 |
|------|------------|-----------|
| APP依賴度 | 更高（強工具屬性） | 相對較低 |
| 內容消費 | 以選車爲主 | 更沉浸內容消費及車友圈社交 |
| 價格帶集中 | 5-15萬佔82% | 5-15萬佔58.1%（更分散） |
| 用戶畫像 | 低齡段未婚更多 | 高線城市更集中 |

**這意味着什麼**：新能源用戶對懂車帝作爲"工具型"平臺的依賴度略低於燃油車用戶。新能源用戶可能更多通過品牌官方渠道、社交媒體等途徑獲取信息。這對懂車帝的內容策略提出了更高要求——需要從純工具型平臺升級爲"內容+社交+交易"的綜合生態。

## 二、新能源車企在懂車帝的投放與合作情況

### 2.1 主要新能源車企與懂車帝的關係

**比亞迪**：關係經歷波折。2023年懂車帝推動CPS（按成交付費）模式切換時，因線索費用大幅上漲（經銷商反映漲幅達三四倍），比亞迪發佈內部郵件要求旗下所有門店停購懂車帝年框。這是對懂車帝商業模式的一次重大沖擊——比亞迪是中國最大的新能源車企，其態度具有行業風向標意義。後續雙方關係有所修復，但這一事件暴露了懂車帝在面對頭部車企時的議價弱勢。

**華爲/鴻蒙智行**：2023年冬測爭議後，華爲與懂車帝、汽車之家、易車三大平臺均暫停合作，引發行業震動。2025年7月的智駕測試中，鴻蒙智行對懂車帝測試結果回應"不予置評"，雙方關係仍較敏感。

**蔚來/小鵬/理想/小米**：這些品牌均參與了懂車帝的各類測試項目（冬測、智駕測試等），但其中小米SU7在2025年智駕測試中表現不佳引發爭議。總體而言，新勢力車企對懂車帝保持合作態度，但對測試結論有時持保留意見。

**特斯拉**：在懂車帝2025年智駕測試中，特斯拉Model 3/Model X以純視覺方案拿下綜合排名前兩位，馬斯克親自轉發測試結果。這一定程度上提升了懂車帝測試的國際影響力。

### 2.2 懂車帝與車企的合作模式

1. **線索/流量合作**：車企和經銷商向懂車帝購買銷售線索，這是懂車帝核心收入來源。
2. **品牌廣告投放**：開屏廣告、信息流廣告、品牌專區等。
3. **內容合作**：包括懂車帝測試項目的車輛提供、聯合測評等。
4. **達人營銷**：通過"懂車星選"產品，在懂車帝和抖音雙端進行達人營銷投放。
5. **以舊換新政策落地**：懂車帝作爲官方授權平臺，爲車企提供補貼申請服務。

### 2.3 關鍵矛盾：測評獨立性 vs 商業合作

懂車帝面臨一個結構性矛盾：

- **作爲內容平臺**：需要通過獨立、嚴苛的測試（冬測、智駕測試）建立公信力和用戶信任
- **作爲商業平臺**：需要維護與車企的合作關係以獲取廣告和線索收入

2023年冬測引發華爲等多家車企質疑，2025年智駕測試再次引發行業爭議。這表明懂車帝在"做裁判"和"做生意"之間的平衡難度很大。車企有時會以暫停合作作爲施壓手段。

## 三、新能源直營模式 vs 經銷商模式對懂車帝線索業務的影響

### 3.1 行業渠道變革：直營"退燒"，經銷商迴歸

2025年第四季度，新能源車企的渠道模式迎來集中變革：

- **騰勢**：在河北、河南、浙江、廣東等核心市場，推進直營店關店或轉讓給經銷商
- **鴻蒙智行**：啓動大範圍直營網絡裁撤，廣東、四川、江蘇等省份渠道調整全面落地
- **理想、蔚來**：此前堅守直營的代表，也開始探索更具成本效益的渠道優化路徑

**核心驅動因素**：一線城市核心商圈直營展廳年租金百萬元，疊加人員、水電物業等支出，單店年運營成本達五六百萬元。200家門店規模的車企，僅開店和運營就需年投入約10億元。在利潤持續承壓的環境下，這一負擔難以爲繼。

行業正加速向"直營+加盟/授權"混合模式轉型：直營保留一線核心商圈的品牌展示功能，加盟和授權渠道負責快速下沉三四線及縣域市場。

### 3.2 對懂車帝線索業務的影響

**利好層面**：

1. **經銷商迴歸擴大線索需求**：直營模式下，車企自建線索獲取體系，對第三方平臺依賴較低；經銷商模式下，經銷商對外部線索的需求天然更強。新能源車企迴歸經銷商體系，意味着更多門店需要購買懂車帝線索。
2. **下沉市場擴容**：低線城鎮汽車銷量及增速遠超一二線城市，經銷商模式更適合下沉市場覆蓋，這擴大了懂車帝的潛在線索客戶池。
3. **CPS模式更契合經銷商利益**：懂車帝推動的CPS（按成交付費）模式，經調整優化後，2024年數據顯示57%的合作經銷商成交量正增長，94.8%的經銷商願意繼續合作。

**風險層面**：

1. **頭部車企自建流量閉環**：比亞迪、理想等頭部車企通過創始人IP、品牌社交媒體等方式自建獲客渠道，降低對懂車帝的依賴。李斌、李想、雷軍等造車大佬打造個人IP，善用抖音、小紅書、視頻號等平臺直接獲客。
2. **線索定價博弈**：CPS模式切換曾引發比亞迪等大客戶抵制。懂車帝在提升線索單價的同時面臨客戶流失風險。
3. **新能源車的在線化購買趨勢**：部分新能源品牌支持線上直接下單，減少了對傳統"留資-跟進-到店"線索鏈路的依賴。

**淨影響判斷**：短期來看，直營轉經銷的趨勢對懂車帝線索業務是利好。但中長期看，頭部車企自建流量體系的趨勢不可逆，懂車帝需要從"賣線索"升級爲"幫成交"，才能維持線索業務的價值。

## 四、懂車帝冬測、續航測試等新能源評測內容的影響力

### 4.1 冬測：從國內到全球的升級路徑

**2023年冬測（爭議之年）**

- 問界M7增程版續航達成率僅31.6%排名倒數第一，引發華爲餘承東公開質疑
- 吉利、長城旗下多款車型續航達成率不到40%
- 問界官方指出，測試前車輛進行了71分鐘空調製熱，期間十餘次開關門窗，嚴重偏離真實使用場景
- 華爲隨後暫停與三大汽車垂直平臺的合作

**2025年全球冬測（升級之年）**

- 升級爲全球測試：在中國黑河、美國阿拉斯加、瑞典于默奧三地進行
- 覆蓋近40個品牌、90多輛車
- 測試科目擴展至基礎用車、主動安全、極限續航、拉力計時等
- 累計行駛近10萬公里
- 獲央視關注和報道，國際化提升品牌影響力

### 4.2 智駕安全測試：2025年最具影響力的評測事件

2025年7月，懂車帝與央視新聞合作，包下15公里真實高速公路及城市道路，對36款主流車型進行輔助駕駛安全模擬測試：

- **高速場景**：6類場景，36款車，183次測試，通過44次，**通過率僅24%**
- **城市場景**：9類場景，26款車，233次測試，通過103次，**通過率44.2%**
- 綜合排名：特斯拉Model 3第一，Model X第二，藍山、小鵬G6、問界M9分列三至五位

這次測試引發巨大社會反響：
- 馬斯克親自轉發並表示認可
- 鴻蒙智行回應"不予置評"
- 公安部交通管理局藉此明確表態：當前"智駕"均爲輔助駕駛，非自動駕駛
- 部分用戶和車企質疑極端場景測試的代表性

### 4.3 評測影響力評估

| 維度 | 評估 |
|------|------|
| 公衆關注度 | 極高，多次登上熱搜，馬斯克轉發提升國際影響力 |
| 行業影響力 | 高，但爭議也大，多家車企質疑方法論 |
| 政策影響力 | 有一定作用，推動公安部對智駕的明確表態 |
| 用戶信任度 | 存在分化，部分用戶認可其獨立性，部分認爲測試標準不公 |
| 競爭壁壘 | 高，冬測/智駕測試已成爲懂車帝的標誌性IP內容 |

**關鍵判斷**：冬測和智駕測試已成爲懂車帝最重要的內容IP和品牌資產。它們帶來了巨大的流量和話題度，但也帶來了與車企關係的緊張。對於IPO前的懂車帝來說，這些評測內容是展示平臺價值的"殺手鐧"，但也需要在方法論的科學性和透明度上持續改進，以維護公信力。

## 五、新能源車企營銷預算的渠道流向

### 5.1 行業營銷費用概覽

2025年第一季度中國車企銷售費用排名中，小米超越比亞迪位居第一，反映出新入局者在品牌建設上的激進投入。不同車企的營銷策略分化明顯：

- **理想**：聲稱營銷費用率全行業最低，接近特斯拉水平。依賴創始人IP和口碑傳播。
- **小米**：高投入策略，利用雷軍個人影響力+多渠道飽和攻擊。
- **蔚來/小鵬**：營銷費用佔比處於高位，但相較此前有明顯下降趨勢。
- **比亞迪**：銷量規模大但營銷投入相對剋制，更多依賴產品力和價格競爭力。

### 5.2 渠道投放格局的結構性變化

**傳統格局被顛覆**：

傳統上，汽車之家、懂車帝、易車三大垂直平臺是車企線上營銷的核心渠道。但這一格局正在被打破：

1. **抖音/短視頻崛起**：造車大佬（李斌、李想、雷軍、餘承東）打造個人IP，在抖音直接獲客。車企品牌官方號也成爲重要的傳播和獲客渠道。
2. **小紅書種草**：在女性用戶和年輕羣體中的影響力日增，成爲新能源車企（尤其中高端品牌）的重要投放陣地。
3. **視頻號/微信生態**：私域運營、社羣裂變成爲車企降低獲客成本的重要方式。
4. **品牌自有渠道**：車企APP、小程序、線下活動等自有渠道的投入加大。

**垂直平臺的壓力**：

車企和經銷商已經開始把預算從汽車之家、懂車帝等垂直平臺轉向抖音、小紅書等"新勢力"渠道。車企在減少對垂直平臺依賴的同時，實現自有銷售線索的大量獲取和快速轉化。

### 5.3 懂車帝能佔到多少？

懂車帝沒有公開披露具體的廣告收入數據。從估值和融資信息推斷：

- 2024年融資約6億美元，估值約30億美元
- 2026年傳聞IPO，擬募集10-15億美元
- 截至2025年8月，DAU突破1000萬，覆蓋3萬+經銷商、110+品牌

**懂車帝的獨特優勢**：

背靠字節系，懂車帝擁有與抖音雙端聯動的獨特能力。數據顯示，用戶在抖音端激發興趣後，約84%會跳轉至懂車帝查看車型庫，78%搜索具體車系並閱讀深度評測。這種"興趣激發(抖音) -> 深度決策(懂車帝) -> 交易轉化"的鏈路是汽車之家和易車不具備的。

**份額估判**：在新能源車企數字營銷預算中，懂車帝（含抖音聯投）可能佔到15%-25%的份額，但這一比例面臨來自品牌自建渠道和新興平臺的持續擠壓。

## 六、智能化（智駕/座艙）內容是否成爲新增長點

### 6.1 智駕評測：已成爲懂車帝2025年最大的內容增長點

2025年7月的智駕安全實測是懂車帝歷史上影響力最大的內容事件之一：

- 與央視新聞聯合制作，提升權威性
- 測試覆蓋36款車、15類高危場景、數百次模擬碰撞
- 馬斯克親自轉發，引發全球關注
- 全網曝光量巨大

懂車帝已明確表態將"加大智能化、安全性實測投入"，並推出"百萬車主評測計劃"，將智能化內容作爲平臺差異化競爭的核心方向。

### 6.2 AI賦能平臺功能：從工具到生態

**2025年：AI選車上線**

懂車帝首次公開AI全景圖，基於平臺5000萬+結構化數據、7.6萬+車型庫、4000+款車實測數據（超100萬條），自主研發AI大模型，形成選車、比車、買車、估價等多元場景的AI智能體。

**2026年北京車展：AI小懂首發**

懂車帝在2026年北京車展正式發佈AI助手"AI小懂"，從"選車"單一場景升級至"選、買、賣、用、玩"五大汽車生活全環節。核心能力包括：
- 高精度智能交互
- 專屬汽車知識庫
- 深度多輪對話
- 海量真實用戶評價整合

**與火山引擎的技術協同**：懂車帝與字節旗下火山引擎合作，打造更智能的汽車內容生態。

### 6.3 增長點評估

智能化內容確實是懂車帝的新增長點，但需要區分兩個層面：

1. **內容維度**：智駕評測等內容帶來大量流量和話題度，但難以直接貨幣化，且可能得罪廣告客戶（車企）
2. **產品維度**：AI選車、AI小懂等智能化功能提升了用戶體驗和平臺粘性，有助於延長用戶生命週期價值

**潛在風險**：智駕評測的爭議性可能導致部分車企減少投放。懂車帝需要在內容影響力和商業利益之間找到平衡。

## 七、充電樁/補能相關服務佈局

### 7.1 懂車帝充電平臺

懂車帝已推出充電公共服務平臺，具體佈局如下：

- **重慶試點**：與"渝易充"App通過市場化合作實現互聯互通，在重慶覆蓋1000餘個充電站、9000餘個充電樁、近1.4萬個充電槍
- **全國擴展**：服務已擴展至31個省份的324個城市，覆蓋主流充電品牌
- **功能**：實時查詢充電站距離、價格、停車費等信息，支持一鍵掃碼、跨平臺使用

### 7.2 定位與策略

懂車帝在補能服務上採取的是**輕資產聚合模式**——不自建充電樁，而是聚合第三方充電服務，爲用戶提供一站式查詢和支付體驗。這與其"汽車生活平臺"的定位一致。

### 7.3 業務價值評估

| 維度 | 評估 |
|------|------|
| 戰略價值 | 高。延伸用戶服務鏈條，從"買車"延伸到"用車"，提升用戶粘性和LTV |
| 收入貢獻 | 目前較小。充電聚合業務競爭激烈（高德、百度地圖等也在做），利潤空間有限 |
| 競爭壁壘 | 低。充電聚合本質是信息服務，技術壁壘不高 |
| 與主業協同 | 中等。可以爲新能源用戶提供一體化體驗，但與核心的線索/廣告業務關聯度有限 |

**判斷**：充電服務是懂車帝"新能源生態"拼圖的一塊，更多是完善用戶體驗的補充業務，短期內不會成爲重要收入來源。但隨着新能源保有量持續增長，這一業務的戰略價值會逐步顯現。

## 八、綜合判斷與關鍵結論

### 8.1 新能源對懂車帝的影響：機遇大於挑戰，但有結構性風險

**核心機遇**：
1. 新能源滲透率突破60%且仍在上升，懂車帝平臺內容和交易生態自然受益
2. 新能源車企從直營迴歸經銷商模式，擴大了線索業務的客戶基礎
3. 智駕評測等新內容IP創造了差異化優勢和流量增長點
4. 抖音+懂車帝雙端聯動形成獨特的"興趣激發-深度決策-交易轉化"閉環

**結構性風險**：
1. 頭部新能源車企（比亞迪、理想等）自建流量體系，降低對第三方平臺的依賴
2. 評測獨立性與商業利益的衝突可能激化——車企用暫停合作施壓
3. 新能源用戶對懂車帝APP的依賴度低於燃油車用戶，平臺粘性面臨挑戰
4. 營銷預算從垂直平臺向社交媒體和品牌自有渠道持續轉移

### 8.2 懂車帝的差異化壁壘

相比汽車之家和易車，懂車帝在新能源時代的核心壁壘包括：

1. **字節系生態協同**：抖音導流 -> 懂車帝轉化，84%的抖音汽車興趣用戶會跳轉懂車帝
2. **評測內容IP**：冬測和智駕測試已形成強品牌認知，央視背書提升權威性
3. **AI技術能力**：依託火山引擎，AI選車/AI小懂等產品領先同行
4. **數據積累**：結構化數據5000萬+，實測數據庫覆蓋4000+款車

### 8.3 對IPO估值的影響

懂車帝正籌備2026年港股IPO，擬募資10-15億美元。新能源業務的表現將直接影響投資者對其成長性的判斷：

- **有利因素**：新能源滲透率持續提升帶來行業順風；全球冬測和智駕評測展示了內容壁壘；AI產品矩陣體現技術能力
- **不利因素**：與頭部車企的關係波動增加收入不確定性；線索業務可能面臨價格天花板；充電等新業務短期貢獻有限

### 8.4 值得持續跟蹤的關鍵指標

1. 懂車帝DAU中新能源意向用戶佔比的變化趨勢
2. 新能源車企（尤其比亞迪、華爲）與懂車帝合作關係的修復情況
3. CPS模式下經銷商的續約率和客單價變化
4. 冬測/智駕測試等內容IP的商業化路徑探索
5. AI選車/AI小懂的用戶滲透率和對轉化效率的提升效果
6. 充電服務的MAU和交易規模增長
