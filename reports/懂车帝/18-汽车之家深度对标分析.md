# 汽車之家（ATHM）深度對標分析

> 研究目的：作爲懂車帝最重要的可比公司，對汽車之家進行全面深度研究，爲懂車帝估值和投資決策提供參照系。
>
> 研究日期：2026年5月

---

## 一、公司概況

汽車之家（Autohome Inc.，NYSE: ATHM / HKEX: 02518）成立於2005年，是中國最早、最大的汽車垂直媒體平臺之一。2013年在紐交所上市，2021年在港交所二次上市。

**股權變遷史：**
- 2016年：中國平安以約16億美元收購汽車之家47.4%股權，成爲控股股東
- 2025年2月：中國平安以約18億美元將41.91%控股權出售給海爾集團
- 2025年8月：海爾集團完成交易交割及董事會改組，正式成爲控股股東

### 2.2 各業務板塊收入明細

| 業務板塊 | 2023年（億元） | 2024年（億元） | 2025年（億元） | 2024同比 | 2025同比 | 2025佔比 |
|----------|---------------|---------------|---------------|----------|----------|----------|

**業務結構變化解讀：**

1. **媒體服務（廣告）持續崩塌**：從2023年的26%佔比降至2025年的18%，兩年累計下滑38%。核心原因是燃油車廠商大幅削減廣告預算，新能源品牌更傾向於抖音、小紅書等新媒體平臺投放。

2. **線索服務（核心收入）開始失速**：2024年尚能持平，2025年加速下滑13.6%。主因是付費經銷商數量減少+每家經銷商平均收入下降（下沉市場客單價低）。

3. **在線營銷及其他（唯一增長）**：包含新零售（空間站/衛星店）、二手車交易、數據產品等，連續兩年增長約8-9%，佔比從31%提升至40%，已接近替代線索服務成爲第一大收入來源。

### 2.3 成本結構

| 項目 | 2025年（億元） | 同比變化 |
|------|---------------|----------|
| 營業成本 | 13.07 | **+41.7%** |
| 銷售及市場費用 | 25.33 | -15.2% |
| 研發費用 | 10.64 | -19.3% |

**關鍵發現：營業成本暴漲41.7%是毛利率急劇下降的直接原因。新零售業務（線下空間站、衛星店）屬於重資產模式，拖累了整體成本結構。研發費用持續縮減，引發對技術投入不足的擔憂。**

## 四、平安時代的戰略變化與執行效果

### 4.1 平安入主（2016-2024年）的三個階段

**第一階段（2016-2018）：蜜月期**
- 規劃"4+1"生態圈：車媒體、車電商、車金融、車生活
- 業績高速增長，股價從收購價翻2.5倍至119美元
- 合作主機廠從87家增至103家，移動日均UV從1,380萬增至2,910萬

**第二階段（2019-2021）：矛盾顯現**
- 平安試圖將用戶資源與金融業務深度融合
- 平臺充斥金融廣告，內容質量和用戶體驗嚴重下滑
- 媒體業務2019年Q4首次負增長，2021年降幅擴大至41.78%

**第三階段（2022-2024）：全面衰退**
- 媒體服務單季收入最低降至2.67億元，佔比不到20%
- 被懂車帝、易車持續蠶食市場份額
- 2025年2月，平安以18億美元"甩賣"控股權給海爾

### 4.2 平安時代的教訓

1. **金融協同失敗**：試圖將媒體平臺變成金融導流工具，破壞了內容生態
2. **人才流失嚴重**：多次換帥導致戰略搖擺不定
3. **錯失新能源和短視頻兩大浪潮**：平安更關注金融變現而非產品創新
4. **估值從120億美元萎縮至約20億美元**：市值蒸發超80%

### 4.3 海爾時代（2025年至今）的初步變化

- 海爾系劉斥空降擔任董事會主席兼CEO
- 戰略方向轉向"家車互聯"：將汽車之家融入海爾智慧家庭生態
- 推出O2O商城業務（2025年9月試運行）
- 基於DeepSeek大模型推出AI智能助手
- 新零售空間站及衛星店網絡突破200家

**海爾的挑戰：** 一個家電企業能否比金融集團做得更好？從家電到汽車的跨界協同邏輯並不比金融協同更清晰。

## 五、四大業務板塊深度分析

### 5.1 線索業務（收入佔比42%，核心現金牛）

**商業模式：** 向經銷商收取年費（CPT模式），提供購車用戶線索。

**當前困境：**
- 行業線索總量10年暴增66倍（從1,000萬條到6.6億條），但乘用車銷量僅增長1.4倍
- 線索質量嚴重注水，經銷商獲客成本4年增加20%，轉化率下降14%
- 付費經銷商數量2025年銳減約20%
- 懂車帝CPS模式（按成交付費）對CPT模式構成降維打擊

**趨勢判斷：線索業務是夕陽模式。CPT按時間收費無法證明效果，經銷商正在用腳投票。**

### 5.2 媒體服務（收入佔比18%，加速萎縮）

**商業模式：** 向汽車品牌商出售展示廣告位、內容營銷服務。

**當前困境：**
- 燃油車品牌預算持續縮減
- 新能源品牌更偏好抖音、小紅書等社交平臺
- 兩年累計下滑38%，佔比從26%降至18%
- 內容形態（圖文爲主）已落後於短視頻時代

**趨勢判斷：傳統品牌廣告在汽車垂直平臺的投放將持續萎縮，這是結構性趨勢。**

### 5.3 在線營銷及其他（收入佔比40%，唯一增長極）

**包含業務：**
- 新零售：線下空間站+衛星店，提供看車、試駕、交易一站式服務
- 二手車：天天拍車平臺，買賣雙向服務
- 數據產品：面向車企的數據分析和決策支持工具
- 交易佣金：促成新車、二手車交易的服務費

**增長驅動：** 連續兩年增長約8-9%，但增速不算快，且新零售業務的重資產模式拉低了毛利率。

### 5.4 AI與數據產品

2025年推出五大數科產品線：
1. AI營銷大腦——智能決策支持
2. AI獲客先鋒——自動化內容生產
3. AI線索大師——精準用戶觸達
4. AI銷冠神器——銷售能力賦能
5. AI查車專家——車況評估

**評估：** AI產品化是正確方向，但目前收入貢獻有限，且依賴外部大模型（DeepSeek），自身技術壁壘不深。

## 六、當前估值分析

### 6.1 核心估值指標（截至2026年5月）

| 指標 | 數值 |
|------|------|
| 美股股價 | ~17.75美元 |
| 總市值 | ~20.5億美元（約150億人民幣） |
| 總股本 | 4.85億股 |
| PE（TTM） | ~10.9x |
| PS（TTM） | ~2.3x（基於9.23億美元收入） |
| 每股淨資產 | ~199.89元（約27.5美元/股） |
| PB | ~0.65x |
| 現金及投資總額 | 213.6億元（約29.5億美元） |
| 企業價值（EV） | **負值**（市值遠低於淨現金） |

### 6.2 估值解讀

**汽車之家目前處於極度低估或者說"陷阱式低估"：**

1. **淨現金超過市值**：公司持有213.6億元現金及投資（約29.5億美元），而市值僅20.5億美元，意味着市場給業務本身的定價爲**負值**。

2. **PE 10.9倍**：看似便宜，但利潤在加速下滑（-14.2%），如果趨勢延續，遠期PE會上升。

3. **PB 0.65倍**：大幅破淨，反映市場對公司未來價值創造能力的悲觀預期。

4. **股價一年跌幅33.8%**：市場持續用腳投票。

5. **2億美元回購計劃**：管理層試圖向市場傳遞信心，但回購規模相對於淨現金體量偏小。

**核心問題：這是價值陷阱還是價值窪地？**

從價值投資角度看，關鍵判斷點在於：
- 收入下滑能否在海爾入主後止住？
- 新零售業務能否以足夠快的速度增長來彌補傳統業務的萎縮？
- 經銷商流失趨勢能否逆轉？

## 七、汽車之家面臨的核心挑戰

### 7.1 被懂車帝蠶食份額

| 維度 | 汽車之家的劣勢 |
|------|---------------|
| 內容形態 | 以圖文爲主，短視頻內容佔比低 |
| 流量來源 | 自有App爲主，缺乏外部流量入口 |
| 用戶畫像 | 老用戶爲主，年輕用戶流失 |
| 線索模式 | CPT年費制，無法按效果收費 |
| 技術能力 | 依賴外部大模型，算法推薦能力不及字節系 |
| 用戶體驗 | 平安時代被金融廣告侵蝕，口碑受損 |

### 7.2 行業結構性變化

1. **新能源滲透率突破50%**：新能源品牌更注重直營和社交媒體營銷，對傳統垂直媒體的依賴度低
2. **經銷商行業洗牌**：燃油車4S店大量關閉，付費經銷商基數縮小
3. **用戶決策路徑變化**：從"搜索-閱讀-決策"變爲"刷視頻-直播-下單"
4. **短視頻平臺全面侵入**：抖音、快手不僅是內容平臺，也在切入汽車交易

### 7.3 管理層頻繁變動的風險

- 平安時代換了多任CEO，戰略缺乏延續性
- 海爾入主後再次換帥，新管理層能否穩定執行是未知數
- 海爾作爲家電企業，對汽車行業的理解深度存疑

| 對比維度 | 汽車之家 | 懂車帝 |
|----------|---------|--------|

| **上市狀態** | NYSE + HKEX 雙重上市 | 籌劃2026年港交所IPO |
| **控股方** | 海爾集團（2025年起） | 字節跳動 |

| **收入結構** | 媒體18%+線索42%+在線營銷40% | 廣告+線索+交易（混合模式） |
| **技術壁壘** | 傳統搜索+內容系統 | 字節系推薦算法+AI |
| **用戶邏輯** | "人找車"（搜索驅動） | "車找人"（推薦驅動） |
| **新能源佈局** | 空間站/衛星店200+家 | 冬測、實測等IP+全品牌覆蓋 |
| **現金儲備** | 213.6億元 | 融資後有充足資金 |
| **增長趨勢** | 連續兩年營收利潤雙降 | 高速增長期 |

### 關鍵差異總結

1. **流量來源的本質差異**：汽車之家是"孤島式"流量，用戶需要主動下載App或訪問網站；懂車帝背靠抖音6億+DAU的流量池，"汽車內容日均消費量達5億人次"，流量獲取成本幾乎爲零。

2. **內容生產方式的代際差異**：汽車之家依賴編輯團隊和少量簽約創作者（2,500+），產出標準化圖文內容；懂車帝擁有750萬創作者的UGC生態，日均200萬作者發佈內容，內容供給量級差距懸殊。

3. **商業模式的進化差異**：汽車之家的CPT模式是"收租"邏輯（不管效果如何都收費），經銷商滿意度低；懂車帝的CPS模式是"分成"邏輯（按成交付費），與經銷商利益綁定更緊密。調研顯示65.9%的經銷商認爲懂車帝線索質量更高，60%表示使用CPS後轉化率顯著提升。

4. **技術能力的代際差異**：汽車之家的技術底層是Web 2.0時代的搜索+分類信息系統；懂車帝繼承了字節跳動的推薦算法引擎，能夠實現"千人千面"的內容和線索分發。

## 九、投資決策分析：買汽車之家還是等懂車帝IPO？

### 9.1 汽車之家的投資邏輯

**看多理由：**
- 淨現金超過市值，理論上"免費"獲得業務
- PE 10.9x，PB 0.65x，估值處於歷史底部
- 2億美元回購計劃提供一定安全邊際
- 海爾入主可能帶來"家車互聯"的新故事
- 即使業務持續萎縮，龐大現金儲備提供了時間窗口

**看空理由：**
- 收入和利潤連續兩年雙降，且下滑加速
- 核心業務（線索+媒體）面臨結構性衰退
- 新零售業務增長不夠快，且拖累毛利率
- 海爾的跨界整合存在巨大不確定性
- 被懂車帝蠶食份額的趨勢難以逆轉
- 付費經銷商銳減20%，基本盤在瓦解
- 創始團隊早已離開，缺乏"靈魂人物"

### 9.2 懂車帝的投資邏輯

**看多理由：**
- 背靠字節跳動/抖音的流量生態，獲客成本極低
- 用戶增長強勁，DAU突破1,000萬且仍在增長
- CPS模式代表行業進化方向
- 750萬創作者的UGC生態難以複製
- 新能源車賽道的結構性受益者
- 如果IPO估值30-50億美元，對應PS約5-8x，仍有合理空間

**看空理由：**
- 財務數據未公開，盈利能力存疑
- IPO後可能面臨估值下行壓力（當前市場對中概股估值偏低）
- 對字節跳動/抖音的流量依賴過重
- CPS模式的盈利性需要驗證（對經銷商有利但平臺利潤可能更薄）
- 汽車垂直賽道本身面臨抖音、小紅書等綜合平臺的侵蝕

### 9.3 投資建議

**核心判斷：如果要在汽車互聯網賽道投資，應該等懂車帝IPO而非買汽車之家。**

理由如下：

1. **趨勢比估值重要**：汽車之家雖然估值便宜，但處於持續下行通道。價值投資的核心不是買便宜貨，而是買好公司。汽車之家當前的困境更像是柯達或諾基亞——不是週期性低谷，而是商業模式被新範式顛覆。

2. **但不要急於買入懂車帝**：懂車帝IPO後需要觀察幾個季度的公開財務數據，驗證其盈利模型。估值30億美元對應的PS倍數需要等收入數據公開後才能評估合理性。

3. **汽車之家的"淨現金超過市值"看似安全，實則是陷阱**：除非管理層願意大規模分紅或私有化（海爾有此可能），否則賬上的現金對小股東而言沒有實際意義。參考過去平安時代，大量現金並未轉化爲股東回報。

4. **最佳策略是等待**：
   - 等懂車帝IPO後公佈2-3個季度財務數據
   - 觀察其收入規模、增長率、盈利能力
   - 如果確認盈利模型可持續，再在合理估值時建倉
   - 汽車之家可作爲對沖標的觀察，但不建議主動建倉

5. **更深層的問題**：汽車垂直平臺是否是一個好賽道？當抖音、小紅書等綜合平臺都在切入汽車內容和交易時，獨立的汽車垂直平臺的護城河究竟有多深？這個問題對汽車之家和懂車帝都適用。

## 十、汽車之家作爲懂車帝估值參照的意義

### 10.1 估值錨定

| 指標 | 汽車之家（實際） | 懂車帝IPO（預期） |
|------|----------------|------------------|
| 市值/估值 | 20.5億美元 | 30-50億美元 |
| 收入 | 64.52億元 | 40-50億元（估算） |
| PS | ~2.3x | ~5-8x（若按30億估值） |
| PE | ~10.9x | 待公開 |
| 增長率 | -8.3% | 預計20-30%+ |

**推導邏輯：** 汽車之家PS 2.3x對應的是負增長的成熟業務；懂車帝如果能證明20%+的收入增速和可持續的盈利模型，PS 5-8x是合理的。但如果懂車帝IPO定價PS超過10x，則需要非常謹慎。

### 10.2 汽車之家的"反面教材"價值

對於評估懂車帝，汽車之家提供了幾個關鍵教訓：

1. **控股股東的"協同效應"可能是毒藥**：平安的金融協同毀掉了汽車之家的內容生態
2. **行業老大不等於永遠安全**：汽車之家曾是絕對龍頭，但短短5年就被懂車帝反超
3. **內容形態變遷的威力巨大**：圖文到短視頻的轉變不亞於PC到移動的轉變
4. **線索模式的護城河很淺**：經銷商對平臺沒有忠誠度，誰的效果好就用誰
