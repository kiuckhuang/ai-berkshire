# 持倉賣出條件

> 建立日期：2026-07-16｜隨季報滾動重審，修訂須留痕
> 修訂記錄：2026-07-27 新增 MiniMax 條款（隨首次建倉同步建立）
> 框架：賣出的合法理由只有三個（李錄）——①發現看錯了；②基本面變壞、買入論文被證僞；③出現明顯更好的機會（"貴到離譜"是③的特例）。漲跌幅、成本價、宏觀情緒都不是理由。

## 通用規則

1. **觸發紅線 = 強制重審，不 = 自動賣出**；重審後論文立不住，賣出時不看成本價
2. **"證僞即賣"與"觸發重審"的區分**：前者留給論文根基被實證推翻的事件，後者留給可能是噪聲、需查明原因的信號（查明爲趨勢後升級爲前者）
3. **執行方式**：想賣時賣 call 分批離場，把"賣不賣"和"什麼價賣"分開（段永平的網易式退出）
4. **更好的機會也是賣出理由（理由③）**：即使現有持倉論文完好、價格不貴，發現明顯更好的標的時可以賣出換倉——門檻是新標的隱含年化回報須高出現有持倉 5 個百分點以上（"一眼胖瘦"），差距不夠一眼看出就不動。注意：不同確定性的標的不能直接比回報點數——低確定性的隱含回報要按勝率打折後再比。像"美團換茅臺"這類交易（困境反轉的寬回報區間 vs 高確定性但增長平緩），本質是用賠率換確定性，不是簡單的回報差比較，需單獨論證

## MiniMax（0100.HK）

**估值離譜線：市值 2,500 億港元以上、且收入與模型地位未同步兌現**（如 ARR 未上一個數量級）。買入論文是對"可能做出一流大模型"的期權定價（買入時市值約 615 億港元）；當市場重新按"已經成功"定價（2026 年 2-3 月峯值約 4,100 億）而基本面未跟上時，期權價值已被透支，應賣還給市場情緒。

| 類型 | 條件 |
|------|------|
| 證僞即賣 | 連續兩代旗艦模型掉出第一梯隊（第三方評測 + API 市場份額雙指標持續下滑）——論文根基"有可能做出一流大模型"被推翻，按應用公司殘值重新決策；閆俊傑離任，或 AGI 綁定承諾實質反悔（捐股/薪酬安排逆轉）——管理層信任無第二道防線 |
| 觸發重審 | B 端 API 收入連續兩季環比下滑（"基礎設施"定位的直接檢驗）；C 端月活到 2027 年中仍未企穩回升；現金跑道縮短到 3 年以內或大額稀釋融資（"不至於歸零"的容錯基礎變薄）；好萊塢訴訟重大不利判決 |

**試探倉特別紀律**：本倉位爲試探倉（約 2%），加倉條件與賣出條件同權——只有 B 端收入連續兩季回升 **且** 旗艦模型穩住第一梯隊時才允許加倉；未滿足前禁止下跌攤平，攤平即繞過鏡子測試。

買入論文見 [MiniMax 鏡子測試](MiniMax_鏡子測試_20260727.md)。

## 爲什麼各家的估值上限不同

PE 是"爲 1 元當期利潤預付的年數"，預付多少取決於：利潤的可預見期、利潤質地（波動性）、利潤歸屬股東的程度（治理與股東回報）。騰訊（微信護城河 + 長青遊戲 + 千億級回購分紅）三項都最強，給 35 倍纔到離譜；PDD 利潤受補貼決策與 Temu 波動、治理披露剋制、股東回報路徑不明，20 倍已隱含"國內中樞保持 + Temu 成功"同時成立。若 PDD 開始大額分紅回購、治理折價收窄，20 倍上限應上調——賣出線和買入論文一樣，是當下證據的函數。MiniMax 是虧損公司，沒有 PE 線可用，估值線只能錨在"期權定價 vs 兌現定價"的市值口徑上——這也是它只配試探倉的原因之一。
